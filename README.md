# PA Lab-Violation Detection System (Faster R-CNN & DeepSORT)

Proyek ini adalah sistem deteksi pelanggaran di laboratorium komputer (seperti bermain game di HP, tidur, dan makan) menggunakan model **Faster R-CNN**, pelacakan objek **DeepSORT**, backend **Flask** dengan **Socket.IO** untuk komunikasi real-time, serta frontend **Next.js** dan interface alternatif berbasis HTML/Flask.

Data deteksi serta foto pelanggaran akan disimpan secara otomatis ke **Supabase Database** dan **Supabase Storage**.

---

## 📂 Struktur Proyek Utama

*   `main.py`: Backend Flask utama yang memuat model Faster R-CNN, melacak objek dengan DeepSORT, mengunggah media ke Supabase, dan mengirimkan event real-time lewat Socket.IO.
*   `mainY.py`: Varian/alternatif backend (misalnya menggunakan YOLO atau konfigurasi eksperimental).
*   `requirements.txt`: Daftar dependensi library Python untuk Backend.
*   `frontend/`: Aplikasi web modern berbasis **Next.js** (TypeScript + Tailwind/CSS).
*   `templates/` & `templates_baru/`: Tampilan halaman web statis alternatif yang dilayani langsung oleh Flask.
*   `uploads/`: Direktori penyimpanan video yang diunggah sementara sebelum diproses.
*   `violations/`: Direktori penyimpanan lokal foto pelanggaran sebagai fallback jika koneksi internet terputus.

## ⚙️ Persiapan dan Instalasi (Setup)

### 1. Database & Storage (Supabase)

Sebelum menjalankan aplikasi, Anda perlu menyiapkan akun dan project di [Supabase](https://supabase.com/):

1.  **Buat Tabel `detections`**:
    Jalankan query SQL berikut di SQL Editor Supabase Anda untuk membuat tabel log deteksi:
    ```sql
    create table detections (
      id bigint generated by default as identity primary key,
      frame_time text not null,
      frame_number int not null,
      object_name text not null,
      confidence float not null,
      tracking_id int,
      timestamp timestamptz default now(),
      image_path text
    );
    ```
2.  **Buat Storage Bucket**:
    *   Buat bucket baru bernama `violations`.
    *   Pastikan untuk mencentang opsi **Public** agar URL gambar deteksi bisa diakses langsung oleh frontend.

---

### 2. Konfigurasi Backend (Python)

1.  **Buat Virtual Environment (Opsional tapi sangat disarankan)**:
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Untuk macOS/Linux
    # atau
    .venv\Scripts\activate     # Untuk Windows
    ```
2.  **Install Dependensi**:
    ```bash
    pip install -r requirements.txt
    ```
3.  **Siapkan File Model**:
    *   Unduh atau salin file weights model Anda (misalnya `best_model (16).pth`).
    *   Letakkan file tersebut di root folder proyek ini (nama file harus sesuai dengan variabel `MODEL_PATH` di `main.py`, default: `best_model (16).pth`).
4.  **Konfigurasi Environment Variable (`.env`)**:
    *   Buat file bernama `.env` di root folder proyek ini (sejajar dengan `main.py`).
    *   Masukkan detail Supabase Anda:
        ```env
        SUPABASE_URL=https://project-id-anda.supabase.co
        SUPABASE_KEY=api-key-anon-atau-service-role-supabase-anda
        ```

---

### 3. Konfigurasi Frontend (Next.js)

1.  **Masuk ke Folder Frontend**:
    ```bash
    cd frontend
    ```
2.  **Install Dependensi Node.js**:
    Aplikasi ini dikonfigurasi menggunakan lockfile `pnpm`. Disarankan menginstalnya dengan `pnpm` (jika belum punya, jalankan `npm install -g pnpm` terlebih dahulu):
    ```bash
    pnpm install
    # atau jika ingin menggunakan npm biasa:
    npm install
    ```
3.  **Konfigurasi Environment Variable (`.env.local`)**:
    *   Buat file `.env.local` di dalam folder `frontend/`.
    *   Isi dengan informasi Supabase:
        ```env
        NEXT_PUBLIC_SUPABASE_URL=https://project-id-anda.supabase.co
        NEXT_PUBLIC_SUPABASE_ANON_KEY=api-key-anon-supabase-anda
        ```

## 🚀 Cara Menjalankan Aplikasi

### Langkah 1: Jalankan Backend Flask
Di terminal utama (pastikan virtual environment aktif jika menggunakannya):
```bash
python main.py
```
Backend akan berjalan di: **`http://localhost:5000`**

### Langkah 2: Jalankan Frontend Next.js
Buka terminal baru, masuk ke folder `frontend`, lalu jalankan:
```bash
cd frontend
pnpm dev
# atau: npm run dev
```
Frontend akan berjalan di: **`http://localhost:3000`**

Buka browser Anda dan akses **`http://localhost:3000`** untuk masuk ke antarmuka dashboard deteksi pelanggaran real-time!

*(Catatan: Anda juga bisa mengakses tampilan web sederhana bawaan Flask langsung di `http://localhost:5000` jika frontend Next.js tidak dijalankan).*

## 🎮 Panduan Penggunaan (How to Use)

Setelah aplikasi backend dan frontend berhasil dijalankan, Anda dapat menggunakannya dengan fitur-fitur berikut:

### 1. Deteksi Pelanggaran dari File Video (Halaman Home)
Halaman utama digunakan untuk memproses file rekaman video CCTV lab yang sudah ada:
1. Akses halaman utama di browser: **`http://localhost:3000`**.
2. Pada panel **Upload Video**, klik area dropzone atau seret file video (format: `MP4`, `AVI`, `MOV` dengan batas maksimal `100MB`) yang ingin dianalisis.
3. Klik tombol **Upload & Deteksi**.
4. Deteksi berjalan secara real-time:
   * **Live Preview**: Menampilkan frame video yang sedang diproses lengkap dengan bounding box hijau di sekitar objek yang terdeteksi beserta ID pelacakannya (misal: `sleep ID:1`).
   * **Detection Logs**: Menampilkan tabel log deteksi real-time. Anda dapat melihat waktu kejadian, nomor frame, nama objek/pelanggaran, dan tingkat keyakinan (confidence score).
   * **Bukti Foto**: Klik gambar mini (thumbnail) di kolom *Gambar* pada tabel log untuk memperbesar bukti pelanggaran.
5. **Hentikan Deteksi**: Jika ingin membatalkan proses deteksi di tengah jalan, Anda dapat mengeklik tombol **Stop** (tombol merah dengan ikon lingkaran) di sebelah tombol upload.
6. **Ekspor Log**: Anda bisa mengeklik tombol **Export Excel** untuk mengunduh log deteksi dari sesi tersebut ke dalam file Excel `.xlsx`.

### 2. Deteksi Pelanggaran dari Live Stream (Halaman Stream URL)
Digunakan jika Anda ingin menghubungkan aplikasi langsung dengan kamera CCTV atau RTSP stream secara live:
1. Klik menu **Stream URL** pada navigasi atas.
2. Masukkan URL streaming video yang valid (misalnya link streaming RTSP, HTTP, atau path webcam lokal) ke kolom input yang tersedia.
3. Klik tombol **Mulai Deteksi Stream**.
4. Sistem Flask akan mencoba melakukan koneksi (termasuk mekanisme retry otomatis) dan memproses aliran video secara real-time. Hasil deteksi akan muncul di layar.

### 3. Halaman Statistik & Ringkasan (Dashboard)
Untuk melihat statistik visual tentang tingkat pelanggaran di laboratorium:
1. Klik menu **Dashboard** pada navigasi atas.
2. Anda akan disajikan metrik total pelanggaran yang terdeteksi dan visualisasi diagram persentase berdasarkan jenis pelanggaran (`sleep`, `eating`, `playing game phone`).

### 4. Halaman Riwayat Pelanggaran (History)
Digunakan untuk melihat, memfilter, dan memeriksa log pelanggaran yang telah lalu yang tersimpan di Supabase:
1. Klik menu **History** pada navigasi atas.
2. Gunakan filter pencarian berdasarkan **Jenis Pelanggaran** atau **Tanggal** untuk mempermudah pencarian.
3. Anda dapat melihat gambar bukti pelanggaran yang disimpan secara permanen di Supabase Storage.
